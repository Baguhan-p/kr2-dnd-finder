# Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Учебный сервис **D&D Finder** — многостраничный интерфейс поиска мастеров и игроков
для настольных ролевых игр (D&D, Pathfinder, Call of Cthulhu и др.),
разработанный на Bootstrap 5.

Предметная область сохранена общей с КР №1 (каталог/магазин услуг),
но реализация выполнена отдельно через CSS-фреймворк.

## Используемый фреймворк
Bootstrap 5.3 (подключение через CDN).

## Способ подключения
- CSS: `https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css`
- JS Bundle: `https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js`
- Собственные стили `css/custom.css` подключаются **после** Bootstrap.

## Страницы проекта
- `index.html` — главная: carousel-герой, новые анкеты мастеров/игроков,
  новые заявки мастеров/игроков, преимущества, подвал.
- `masters.html` — анкеты мастеров: сетка карточек, фильтры, сортировка, пагинация.
- `players.html` — анкеты игроков: сетка карточек, фильтры, сортировка, пагинация.
- `master-requests.html` — заявки «мастер ищет игроков».
- `player-requests.html` — заявки «игрок ищет мастера».
- `request.html` — страница заявки: подробности, участники, комментарии,
  кнопки «Зарезервировать место / Откликнуться» (modal + toast).
- `profile.html` — публичный профиль мастера/игрока: tabs (Обзор / Отзывы /
  Активные заявки), рейтинг, кнопка «Связаться» (modal).
- `search.html` — глобальный поиск по анкетам и заявкам с фильтрами.
- `faq.html` — частые вопросы (accordion).
- `support.html` — техподдержка и «О нас» (форма на Bootstrap-классах).

## Реализованные Bootstrap-компоненты
`navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `toast`, `accordion`,
`tabs (nav-tabs)`, `carousel`, `pagination`, `breadcrumb`, `table`,
`form-control`, `form-select`, `input-group`, `form-check`, `list-group`.

## Сетка и адаптивность
Используются `container`, `row`, `col-*`, адаптивные классы
`col-12 / col-md-6 / col-lg-4 / col-lg-3`, отступы `g-*`, `my-*`, `mb-*`, `p-*`.
Проверены диапазоны 360px / 768px / 1024px / 1440px.

## Самостоятельные доработки (сверх базовой инструкции)
- Единый layout (шапка/подвал/модалка/toast) инжектится через JS
  (`js/layout.js`), активный пункт меню определяется автоматически по URL.
- Данные вынесены в `js/data.js`; каталоги, профили, заявки и поиск
  рендерятся динамически через DOM API.
- Рабочие фильтры, сортировка и клиентская пагинация на 4 страницах каталога.
- Рабочий глобальный поиск по всем типам сущностей.
- Интерактив: резервирование места и отклик через modal + toast,
  добавление комментария, форма поддержки с валидацией.
- Профиль с вкладками tabs и рейтингом звёздами.
