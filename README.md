# D&D Finder

## Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Многостраничный интерфейс сервиса поиска мастеров и игроков настольных ролевых игр (D&D, Pathfinder, Call of Cthulhu, Shadowrun, Cyberpunk RED). Реализованы каталоги анкет с фильтрами, сортировкой и пагинацией, заявки «мастер ищет игроков» и «игрок ищет мастера» с бронированием мест, публичные профили с рейтингом и отзывами, глобальный поиск, FAQ и служба поддержки. Проект выполнен как отдельная реализация предметной области через CSS-фреймворк (не адаптация КР №1).

## Используемый фреймворк
Bootstrap 5.3.

## Способ подключения
Bootstrap подключён через CDN. Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы настраивать тему фреймворка через CSS-переменные `--bs-*`, не заменяя его компоненты.

CSS (в `<head>`, перед `custom.css`):
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<link rel="stylesheet" href="css/custom.css">
```
JavaScript Bundle (перед `</body>`):
```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```
Bundle необходим для работы `navbar` (мобильное меню), `modal`, `accordion`, `carousel`, `nav-tabs`, `toast`, `offcanvas`, `dropdown`, `tooltip`.

## Реализованные Bootstrap-компоненты
- `navbar` — адаптивная навигация с мобильным бургером и глобальным поиском;
- `card` — карточки мастеров, игроков и заявок;
- `btn` (+ варианты `btn-primary`, `btn-outline-primary`, `btn-success`, `btn-danger`, `btn-secondary`, `btn-group`) — действия и переключение вида каталога;
- `badge` — метки типа («Мастер»/«Игрок»), статусов мест и систем;
- `alert` — информационные пояснения на страницах каталогов и поддержки;
- `modal` — окна «Связаться» и подтверждения бронирования места;
- `toast` — уведомления об отправке формы, бронировании и комментарии;
- `accordion` — блок FAQ;
- `carousel` — hero-слайдер на главной;
- `nav-tabs` — вкладки профиля (Обзор / Отзывы / Активные заявки);
- `pagination` — постраничный просмотр каталогов;
- `breadcrumb` — хлебные крошки на внутренних страницах;
- `table` (+ `table-striped`, `table-bordered`, `table-responsive`) — характеристики заявки;
- `list-group` — список участников кампании и активных заявок;
- формы: `form-control`, `form-select`, `input-group`, `form-check` — заявки, поддержка, модалки;
- сетка: `container`, `row`, `col-12 / col-md-6 / col-lg-4 / col-lg-3`, отступы `g-*`, `my-*`, `mb-*`, `p-*`.

## Технологии
HTML5, CSS3, JavaScript (ES6+, динамический рендеринг через DOM API), Bootstrap 5, Git, GitHub.

## Как запустить
1. Клонируйте репозиторий.
2. Откройте `index.html` через Live Server (или любой статический сервер).
3. Данные хранятся в `js/data.js` и рендерятся на клиенте — бэкенд не требуется.

## Самостоятельные доработки (сверх базовой инструкции)
1. **Расширение набора страниц** с обязательных 4 до 10: добавлены `masters`, `players`, `master-requests`, `player-requests`, `request`, `profile`, `search`, `faq`, `support` — собственные страницы и сценарии, расширяющие структуру проекта.
2. **Более сложная структура каталога**: четыре каталожные страницы построены одним переиспользуемым движком `js/catalog.js`, который по атрибуту `data-catalog` на `<body>` собирает нужный набор карточек, фильтров и сортировок.
3. **Рабочие клиентские фильтры, сортировка и пагинация** на всех четырёх каталожных страницах (фильтр по системам/формату/городу/опыту/свободным местам, сортировка по рейтингу/опыту/имени/времени, постраничный просмотр по 6 карточек) — улучшены фильтры, каталог и таблицы.
4. **Страница глобального поиска** `search.html` с фильтрами по типу, системе, формату и городу, ищущая одновременно по анкетам и заявкам — собственный сценарий поверх базового каталога.
5. **Единый layout через JS**: шапка, подвал, модалки и контейнер toast инжектятся `js/layout.js` на всех страницах, активный пункт меню подсвечивается автоматически по URL — устранено дублирование навигации и обеспечена визуальная целостность.
6. **Фэнтезийная тема без замены компонентов**: палитра, фоны карточек/модалок/таблиц/аккордеона и акценты заданы переопределением CSS-переменных Bootstrap `--bs-*` в `:root` (включая `--bs-*-bg-subtle` для `alert`), плюс тематические шрифты Cinzel/Spectral и декоративные градиенты в `custom.css` — аккуратная настройка темы и улучшение визуальной целостности.
7. **Интерактивный пользовательский сценарий заявки**: бронирование места и отклик проходят через `modal` с подтверждением и `toast`, комментарий добавляется в DOM без перезагрузки, форма поддержки использует встроенную валидацию Bootstrap — улучшен сценарий заявки.
8. **Профиль с вкладками `nav-tabs`**, рейтингом-звёздами и списком активных заявок — дополнительные компоненты поверх базовой карточки товара.

## Способы проверки проекта
1. Открыть `index.html` — проверить `carousel`-герой, четыре блока новых анкет/заявок, блок преимуществ и футер.
2. Перейти в `masters.html` / `players.html` — применить фильтры (система, формат, город, опыт), сменить сортировку, пролистать пагинацию; убедиться, что счётчик «Найдено» и сетка `col-12 / col-md-6 / col-lg-4` перестраиваются.
3. Открыть `master-requests.html` / `player-requests.html` — проверить метки свободных мест (`badge`) и переход по карточке.
4. Открыть любую заявку (`request.html?type=master&id=1`) — проверить `table` характеристик, `list-group` участников, кнопку «Зарезервировать место» → `modal` → `toast`; добавить комментарий.
5. Открыть профиль (`profile.html?type=master&id=1`) — переключить вкладки `nav-tabs`, проверить рейтинг и список активных заявок, нажать «Связаться» → `modal`.
6. Воспользоваться глобальным поиском `search.html` и поиском в шапке — проверить фильтрацию по типу/системе/формату/городу.
7. Открыть `faq.html` — проверить работу `accordion`.
8. Открыть `support.html` — отправить форму с пустыми полями (должна сработать валидация Bootstrap) и корректно (должен появиться `toast`).
9. В DevTools проверить ширины 375 / 768 / 1024 / 1440 px: `navbar` сворачивается в бургер, колонки перестраиваются, sticky-фильтры отключаются на мобильных, таблицы не ломают страницу.
10. Проверить консоль браузера на отсутствие ошибок подключения Bootstrap и JS.
